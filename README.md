# Techno-Stress Calculator

A simple Java console program that calculates a techno-stress score
based on a 5-point rating scale.

## Features
- Asks 5 statements, each rated from 1 (Strongly Disagree) to 5 (Strongly Agree)
- Checks that every rating is between 1 and 5
- Calculates the total score out of 25
- Shows the stress level: Low, Moderate or High
- Saves each result to results.txt

## How to run
javac Main.java
java Main

## Note
The statements used here are sample items for demonstration.
This project was inspired by my psychology research on developing
a techno-stress scale for IT employees.

## Built with
Java (Scanner, loops, conditions, file handling)
